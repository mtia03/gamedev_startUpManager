시작할 때의 자금을 자본금으로 치고, 자산/ 부채 + 자본 을 제무재표의 형태로 보여주는 것도 괜찮을 것 같아. 경영관리에 관한 내용인거지.
자본금은 시작할 때의 자금으로 보고, 4-8주 마다 제무 제표를 갱신하는거야, 주차를 넘길때도 그때 든 비용 등을 알 수 있고. 물론 구체적인 판매 활동 이런걸 하지는 않고 보통 사업 -> 이득/인건비 필요한 설비 이런걸 구성하면 좋을 것 같아.
이 사업을 할땐 이 설비가 필요하고, 노무비는 이정도로 들고 이런거. 사업 종류에 따른 필요 설비 자산도 정해 놓으면 좋을 것 같고. 
부채 시스템도 넣어두면 좋을 듯. 제무재표를 수익 비용 대응 원칙 등을 적용해서 빡세게 정확하게 적을지, 아니면 직관적으로 단순 정보만 보여줄 지는 생각을 해봐야할 것 같아.
